## Overview

Cubes Editor is a compact 3D editor that runs in the browser and is designed around cube arrays. Its Minecraft-inspired setting gives users a recognizable way to create, examine, and revise structures assembled from separate cube elements.

The project is aimed at anyone who needs a simple block-based 3D editing workflow rather than a full-scale, complicated editor. Since the application is web-based, it can be used from a compatible browser through the published project page.
